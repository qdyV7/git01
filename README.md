# Git学习项目文档

## 项目概述

这是一个用于学习和演示Git版本控制系统的项目。项目包含了多个文本文件，用于演示Git的各种功能，包括提交、分支、合并和冲突解决。

## 使用说明

### 基本操作示例

#### 1. 克隆项目
```bash
git clone <repository-url>
cd <project-directory>
```

#### 2. 查看文件历史
```bash
git log --oneline git01.txt
```

#### 3. 查看文件差异
```bash
git diff HEAD~1 git01.txt
```

#### 4. 创建新分支进行实验
```bash
git checkout -b feature/new-experiment
echo "新的实验内容" >> git01.txt
git add git01.txt
git commit -m "添加新的实验内容"
```

#### 5. 合并分支
```bash
git checkout master
git merge feature/new-experiment
```

### 冲突解决演示

1. 主分支包含："主干修改冲突演示"
2. 特性分支包含："分支修改冲突演示"
3. 最终合并结果：两个内容都被保留

## 故障排除

### 常见问题

1. **合并冲突**: 参考 `git01.txt` 中的冲突解决示例
2. **推送被拒绝**: 先拉取最新更改，然后再推送
3. **文件丢失**: 使用 `git reflog` 查找丢失的提交
